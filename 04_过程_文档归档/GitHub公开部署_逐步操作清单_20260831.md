## 1) 安装 git + 首次提交（需有网环境）

| 步骤 | 操作 | 校验 |
|------|------|------|
| 1.1 | `winget install -e --id Git.Git` | 出现 `git --version` 即成功 |
| 1.2 | 进项目目录，运行 `powershell -ExecutionPolicy Bypass -File .\00_git_init_safety.ps1` | 末尾显示「安全门通过」绿色字样；若显示红色 `[!!!]`，先处理泄漏再继续 |
| 1.3 | `git init`（脚本已含，可跳过）+ 设置 `git config user.name/email` | — |
| 1.4 | **安全 add**：逐个 `git add README.md .gitignore LICENSE CONTRIBUTING.md CHANGELOG.md THIRDPARTY.md .github/ 00~04各层` | 严禁 `git add -A` |

## 3) 分支保护 + 社区文件

- [ ] **Actions 权限**：Settings → Actions → General → Workflow permissions 保持「Read repository contents」默认
- [ ] **分支保护**：Settings → Branches → Add rule → 主分支 → 勾选「Require pull request reviews before merging」（可选，单人仓库可视需关闭）
- [ ] 上传本机 SECURITY/CONTRIBUTING/FUNDING/THIRDPARTY/CHANGELOG（若未随 commit 推上去，可在仓库 Add file 逐份贴入，注意 UTF-8）

## 4) 安全与合规项（网页端）

| # | 项 | 位置 | 操作 |
|---|----|------|------|
| 4.1 | **默认分支** | Settings → General → Default branch | 确认为主线分支 |
| 4.2 | 禁用危险功能 | Settings → General → Features | 关 `Wikis`/`Projects`（可选，防泄私） |
| 4.3 | **依赖告警** | Settings → Security & analysis | 开 Dependabot alerts（本仓为文档+脚本，影响小） |
| 4.4 | **Secret Scanning** | Settings → Code security and analysis | 开「Secret scanning」+ **push protection** |
| 4.5 | **CodeQL** | Settings → Code security and analysis → Code scanning | Create 默认 CodeQL workflow（扫描 py/ps1） |
| 4.6 | 空扫描自检 | Actions 页 | 首次 CodeQL/secret 运行无 HIGH 即达标 |
| 4.7 | **转 Public** | Settings → General → Danger Zone | 确定后再转；转前再跑一遍 `00_git_init_safety.ps1` |
