## 四、固件逆向成果（EC / WMI / NVIDIA）

### 4.1 EC 寄存器地图（EC0 Field, SystemMemory 0xFED50000，全部实测+DSDT 双重确认）

| 地址 | 位/字段 | 含义 | 状态 |
|------|---------|------|------|
| 0x43E | CPTM | 性能模式标志 | 只读 |
| 0x44F | VGAT | GPU 状态 | 只读 |
| 0x460 | FFAN (4bit) | 风扇模式 | 只读 |
| 0x461/0x469 | PWM | 风扇 PWM（EC 私有，ACPI 无字段） | **可写（fan_test.py 直写已验证）** |
| 0x49F | ADPT | 适配器状态（0x0A=AC） | 只读 |
| 0x751 | bit4 TBME + bit7 UFME | 实验排除：不在 CPU 频率路径 | 排除 |
| 0x783 | APL1/2/4+APTC/APTN | 平台功耗表 | 只读 |
| 0x7C4 | bit3 DBEN + bit5 DBST | Dynamic Boost 使能/状态 | DBEN=1（当前） |
| 0x7D4 | CPUA | CPU 功耗×8 系数 | 只读 |
| 0x7D5 | DBAP | DB 附加功耗（0x19=25W） | MXDB=0x19 → 115+25=**140W 实锤** |
| 0x7D7 | CGCT | GPU 控制 | 只读 |
| 0xEA0 区 | UVER+CCI0-3+CTL0-7+MGI0-F+MGO0-F | 自定义风扇曲线表 | 全 0 = 未启用；**逆向放弃**（见 §九） |
| 0x744 | CTVA+DBCT+MXDB+MIDB | DB 上限/当前 | MXDB=0x19(25W) |

### 4.2 NVIDIA 固件通路（SSDT5 NPCF, HID NVDA0820, UUID 36b49710-2483-11e7-9598-0800200c9a66）

- Case2 = DBEN/DBST 状态机；Case3/4 = MOID 读写表
- 命令 0x73（DB 控制）/ 0x1176（CGCT）/ 0x75/0x1175（WMEN）/ 0x2273（ATPP）
- **Linux 等效已实现**：nvidia-powerd 管理 DB（140W 生效）

### 4.3 WMI 事件机制（重要运维知识）

- 电源插拔 → EC _Q53 → `WMBC(0,3,OSDT)` → `Notify(AMW0,0xD2)` → WMI 事件 `000000d2`
- **0xD2 同时被 Fn+F4 复用**（固件缺陷）→ acpid 误判为 WiFi 切换（见 §六）

## 五、TUXEDO 路线结论（❌ 不可行，已定论）

- tuxedo-drivers 4.22.3 安装成功，uniwill_wmi + tuxedo_io 加载成功，GUID 全匹配
- **ioctl 读 EC 全部返回 0**：DSDT 反编译实锤——本机 AMW0 只有 WQAA/WQAB/WQAC + WSAA/WSAB/WSAC + WMBA/WMBB/WMBC + WQBA 数据表，**无 WQBC 方法**（uniwill_wmi 依赖），WMI evaluate 静默失败
- 同 GUID 不同方法集（MECHREVO 魔改固件）→ 任何 TUXEDO/uniwill 通用驱动**不可用**
- 已干净卸载（apt remove + rmmod + 删源），无残留
- GamingCenter3_Cross.dll = 28MB 原生程序集（非 .NET），无 WMI GUID 字符串 → 硬件控制 = 系统级驱动直写 EC MMIO；Linux 替代 = 直写 EC（已实现 90%）
