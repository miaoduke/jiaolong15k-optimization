## 四、铁律（本机适配版，违反 = 数据作废 / 风险自负）

> 继承自目录 `AI自主科学优化SOP_Linux_v1` 与 `00_交接手册`，阈值按 7435H 实测调整。

### 4.1 安全红线（测试/满载时）

| 红线 | 阈值（本机） | 说明 |
|------|-------------|------|
| 起始满载温度 | **>75°C 禁止开跑** | 热态满载 = 热积累 + 尖峰叠加（历史教训） |
| 测试中温度 | **>92°C 立即停止** | 7435H 评测单烤可至 97.5°C，但那是原厂硅脂；本机空闲 54°C，余量未知，先测基线 |
| 紧急熔断 | **>95°C 无条件冷却 120s** | 距热断线仅 5°C |
| 轮间冷却 | ≥45s（温升 <5°C 时 ≥10s） | 热积累效应实测 -7~-15%/轮 |
| 单轮满载 | ≤60s（长测分 3 段，段间冷却） | — |
| 写入操作 | 先记录原值，再写，写后必回读 | sysfs 立即可验（目录通用原则） |

### 4.2 测试采样协议（1s 采样铁律）

```bash
# 本机温度源: k10temp (AMD)
sensors -u k10temp-pci-00c3 2>/dev/null | grep -A1 "Tctl" | head -2

# 1s 采样循环 (bg) + 满载 (fg), 20s:
( for i in $(seq 1 20); do
    T=$(sensors -u k10temp-pci-00c3 2>/dev/null | awk '/temp1_input/{print $2; exit}')
    F=$(awk '{s+=$1;n++} END{if(n)printf "%.0f", s/n/1000}' /sys/devices/system/cpu/cpu[0-9]*/cpufreq/scaling_cur_freq)
    echo "t=${i}s ${F}MHz ${T}°C"; sleep 1
  done ) &
SAMPLER=$!
stress-ng --cpu $(nproc) --timeout 20s
wait $SAMPLER
```

**教训**：turbostat 5s 采样会平滑掉 1-2s 尖峰，必须 1s（或 0.25s）采样。

### 4.3 功耗测量（本机 RAPL 接口可用）

```bash
# 本机 /sys/class/powercap/intel-rapl:0 实际是 AMD RAPL 的通用接口（命名沿用 Intel）
# 与目录 SOP 相同方法可直接用：
E0=$(sudo cat /sys/class/powercap/intel-rapl:0/energy_uj)
stress-ng --cpu $(nproc) --timeout 20s
E1=$(sudo cat /sys/class/powercap/intel-rapl:0/energy_uj)
awk "BEGIN{printf \"%.1f W\n\", ($E1-$E0)/1000000/20}"
```

### 4.4 变量控制（必记两项）

1. **环境温度**：测试前后记录 `sensors | grep -i acpitz`（本机约 27-30°C）。室温每升 1°C ≈ CPU 满载 +~0.95°C，**不能线性修正**；前后差 >2°C 必须注明。
2. **GPU 状态**：本机为**独显直连（7435H 无核显）**，GPU 始终参与显示。测试前后记录
   `nvidia-smi --query-gpu=utilization.gpu,temperature.gpu,power.draw`，保持 GPU 同态（都空闲或都活跃）。
   ⚠️ 与旧 Intel 机不同：本机**没有**"独显/集显切换"变量，GPU 状态必须是"空闲渲染 vs 3D 负载"同态。

### 4.5 测试纪律

1. 测试前 `ps aux --sort=-%cpu | head -5`，任何 >10% CPU 的进程处理掉（renice / 等待），
   满载轮温升 <15°C 且吞吐 <预期 60% → 后台污染，数据作废重测。
2. 满载测试前必须温度 ≤65°C。
3. 任何 sysfs 写入：先记录原值 → 写入 → 回读确认。
4. **跨环境对比**：换内核/换 BIOS/重装后必须先重测基线，不得沿用旧阈值。
5. **电压红线**：RyzenAdj **不做任何电压调整**（Rembrandt 移动端无可靠降压路径，全部方案只用功耗/温度墙）。这是本机相对 Intel 机的**新增铁律**——目录里"电压只能为负"的规则在本机简化为"不做电压操作"。
6. **不刷 BIOS**：⚠️ 铁律级警告——贴吧/B站流传的"蛟龙15/16/17K 7735H 通刷 XMG BIOS"仅适用于 **7735H**，**7435H 机型严禁刷 7735H BIOS**（实锤不开机）。本机 BIOS 版本 N.1.23MRO20 已含 AGESA RembrandtPI，键盘 DSDT 问题 6.5+ 内核已修复，**无刷 BIOS 需求**。
7. **文档更新后必须同步文件夹时间戳**：⚠️ 每次修改/新增方案文档（00-10 系列、脚本）后，必须将方案文件夹名 `蛟龙15K_7435H_优化方案_YYYYMMDD` 中的日期更新为**当天日期**（YYYYMMDD，如 20260820），保证文件夹名反映最后修改日。备份/历史快照文件夹（会话备份等）**不更新**（快照是历史记录）。

## 五、工具选型决策（本机）

| 工具 | 决策 | 理由 |
|------|------|------|
| **TLP 1.10+** | ✅ 离电场景主力 | 2026 实测比 PPD 空闲低 ~0.5-2W；支持 amd-pstate EPP + CPU_BOOST（内核 6.11+ ✅）；统一管理 USB/PCI/WiFi/NVMe |
| **power-profiles-daemon** | ❌ 停用（与 TLP 冲突） | 官方明确冲突；且本机无 platform_profile 接口，PPD 只能管 CPU 子项，价值低 |
| **PowerTOP** | ⚠️ 仅诊断，不做自动调优 | 与 TLP 同改参数会互踩（2026 指南共识）；`powertop --auto-tune` 谨慎 |
| **nvidia-powerd** | ✅ 场景 A 启用 | Dynamic Boost 140W 解锁；AMD CPU 侧要求已满足（CPPC nominal_freq 存在） |
| **RyzenAdj** | ⚠️ 可选（场景 B/C 进阶） | Rembrandt 部分支持（stapm ⚠️ / fast ✅ / slow ✅ / tctl-temp ✅ / vrm ✅）；/dev/mem 后端本机可读；**仅功耗/温度，不做电压** |
| **stress-ng / lm-sensors / cpupower** | ✅ 必装 | 测试与监控 |
| **s-tui / powerstat** | ✅ 推荐 | 监控与离电功耗统计 |
