## 一、工具安装（一次性）

```bash
sudo apt update

# 监控/测试
sudo apt install -y lm-sensors stress-ng linux-tools-common cpupower
sudo sensors-detect --auto   # 之后重开终端

# 电源管理（TLP 与 PPD 二选一，本方案用 TLP）
sudo apt install -y tlp tlp-rdw

# 离电功耗统计（可选）
sudo apt install -y powerstat

# 场景 A 需要（Dynamic Boost）
sudo apt install -y nvidia-powerd

# 可选进阶（RyzenAdj，场景 B/C 可选）：
sudo apt install -y build-essential cmake libpci-dev git
git clone https://github.com/FlyGoat/RyzenAdj.git /tmp/RyzenAdj
cd /tmp/RyzenAdj && mkdir build && cd build && cmake -DCMAKE_BUILD_TYPE=Release .. && make
sudo cp ryzenadj /usr/local/bin/ && ryzenadj --help | head -5   # 验证
```

## 二、冲突处理（TLP vs PPD — 必须二选一）

```bash
# 停用 PPD（本方案统一用 TLP）
sudo systemctl stop power-profiles-daemon
sudo systemctl disable power-profiles-daemon

# 启用 TLP
sudo systemctl enable --now tlp

# 验证状态（不应同时 active）
systemctl is-active tlp power-profiles-daemon
# 期望: tlp=active, power-profiles-daemon=inactive
```

> 回退（若想用 PPD 而非 TLP）: `sudo systemctl stop tlp && sudo systemctl disable tlp && sudo systemctl enable --now power-profiles-daemon`

## 三、基线测试协议（任何优化前必做）

### 3.1 环境检查

```bash
sensors | grep -i acpitz                  # 环境温度 (27-30°C 正常)
nvidia-smi --query-gpu=utilization.gpu,temperature.gpu,power.draw   # GPU 状态
ps aux --sort=-%cpu | head -5             # 后台污染检查 (>10% 需处理)
cat /sys/devices/system/cpu/cpu0/cpufreq/energy_performance_preference  # EPP 现状
```

### 3.2 AC CPU 满载基线（1s 采样，20s）

```bash
( for i in $(seq 1 20); do
    T=$(sensors -u k10temp-pci-00c3 2>/dev/null | awk '/temp1_input/{print $2; exit}')
    F=$(awk '{s+=$1;n++} END{if(n)printf "%.0f", s/n/1000}' /sys/devices/system/cpu/cpu[0-9]*/cpufreq/scaling_cur_freq)
    echo "t=${i}s ${F}MHz ${T}°C"; sleep 1
  done ) &
SAMPLER=$!
stress-ng --cpu $(nproc) --timeout 20s
wait $SAMPLER
```

**判定（2026-08-17 实测，原厂散热）**:
- 🚨 **实测：满载 4s 冲 95.5°C @ 59.6W（两次复现）→ 原厂散热激进，必须温度墙守护**
- 满载频率 4.0GHz（频率未被限，但温度不可持续）→ 日常高负载（编译/游戏）需监控温度
- **后续处理（2026-08-17 晚）**：部署 ryzenadj tctl 92°C 墙 + watchdog 守护后实测满载 3.7-3.9GHz 稳定（见 08 报告）
- 温度墙管理：默认 92°C，可 `脚本/set_tctl.sh` 调整（90-95）；换脂不做（已取消）

### 3.3 RAPL 功耗测量

```bash
E0=$(sudo cat /sys/class/powercap/intel-rapl:0/energy_uj)
stress-ng --cpu $(nproc) --timeout 20s
E1=$(sudo cat /sys/class/powercap/intel-rapl:0/energy_uj)
awk "BEGIN{printf \"CPU包功耗: %.1f W\n\", ($E1-$E0)/1000000/20}"
```

### 3.4 离电功耗基线（拔电后）

```bash
powerstat 5 24    # 5s 间隔 24 次，看 Average
# 拔电前记录电池%: cat /sys/class/power_supply/BAT0/capacity
```

## 四、场景切换命令速查

### 场景 A（带电极致性能）

```bash
# 1) 动态 140W（安装后一次性）
sudo systemctl enable --now nvidia-powerd
# 验证: 3D 负载时 nvidia-smi power.limit 上探 140W

# 2) TLP AC 档（若已按 02/03 配置过离电档）
#    /etc/tlp.conf 确保: CPU_SCALING_GOVERNOR_ON_AC=performance / CPU_ENERGY_PERF_POLICY_ON_AC=performance / CPU_BOOST_ON_AC=1
sudo systemctl restart tlp

# 3) Fn+X 狂暴模式（硬件，无命令）
# 4) 可选 RyzenAdj 温度墙（原厂散热建议 92°C）
sudo ryzenadj --tctl-temp=92 && sudo ryzenadj --info | grep -iE "tctl|temp"
```

### 场景 B（离电平衡）

```bash
# /etc/tlp.conf 用 02 文档 §二 配置后:
sudo systemctl restart tlp
# 验证（拔电）: cat /sys/devices/system/cpu/cpu0/cpufreq/energy_performance_preference → balance_performance
# GPU 功耗墙: 手动 -pl 无效（04 陷阱 11），由 nvidia-powerd/RTD3 自动管理
echo 60 | sudo tee /sys/class/backlight/nvidia_0/brightness
```

### 场景 C（离电极限续航）

```bash
# /etc/tlp.conf 用 03 文档 §二 配置后:
sudo systemctl restart tlp
# 验证（拔电）: EPP=power, scaling_max_freq=2400000
# GPU: 手动 -pl 无效（04 陷阱 11），RTD3 自动省电
echo 30 | sudo tee /sys/class/backlight/nvidia_0/brightness
sudo systemctl disable --now bluetooth
```

## 五、一键切换脚本（脚本/ 目录）

| 脚本 | 用途 |
|------|------|
| `apply_mode.sh {a|b|c}` | 切换三场景（TLP 配置 + GPU 墙 + 屏幕亮度 + 蓝牙） |
| `measure_thermal.sh` | 1s 采样满载测试 + RAPL 功耗（自带红线: >92°C 自动终止） |
| `record_state.sh` | 记录当前环境/GPU/EPP/功耗墙快照（用于"改前留痕"） |
| `reset_all.sh` | 回滚到保守默认（EPP=performance、GPU 115W、TLP 默认） |

> 用法: `sudo bash 脚本/apply_mode.sh b` 等。脚本见 `脚本/` 目录，应用前可自行审阅。

## 六、回滚预案（按场景）

```bash
# GPU 功耗墙（手动 -pl 无效，04 陷阱 11；此命令保留仅为尝试，实际由 powerd 管理）
sudo nvidia-smi -pl 115 2>/dev/null || true
# Dynamic Boost
sudo systemctl disable --now nvidia-powerd
# EPP 手动（不经 TLP）
for c in /sys/devices/system/cpu/cpu*/cpufreq/energy_performance_preference; do echo performance | sudo tee $c >/dev/null; done
# 蓝牙
sudo systemctl enable --now bluetooth
# 亮度
echo 100 | sudo tee /sys/class/backlight/nvidia_0/brightness
# TLP → PPD 切换见 §二
# RyzenAdj: 重启自动失效（无需回滚）
```
