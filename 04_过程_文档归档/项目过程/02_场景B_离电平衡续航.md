# 02_场景B_离电平衡续航.md — 离电日常办公（续航与性能平衡）

> **目标**: 离电时日常办公/编程/浏览器流畅（CPU 可爆发），续航 **3.5-4.5h+**（对标评测 PCmark10 3h58m）
> **关键**: 7435H **无核显**，GPU 必须常驻（显示渲染）→ 离电省电核心 = **CPU EPP + TLP 激进策略 + 屏幕/无线**
> **铁律**: 先读 00 文档；TLP 与 PPD 冲突必须二选一（本方案用 TLP，停 PPD）

---

## 一、当前问题（实测）

1. **EPP 全核锁 performance**：`governor=performance` 导致 amd-pstate-epp 将 EPP 强制为 performance
   （TLP FAQ 实证：governor=performance 时 EPP 锁死）。离电必须改为 `governor=powersave + EPP=balance_performance`。
2. **无 platform_profile 接口**：PPD 无法切换平台配置，只能靠 EPP/TLP 手动管理。
3. **GPU 空闲功耗**：RTD3 fine-grained 已启用（空闲自动 D3），基础良好；不做激进操作，靠 RTD3 + TLP 兜底。
4. **屏幕亮度 100%**（实测 backlight=100/100）→ 最大省电杠杆之一，办公建议 40-60%。

---

## 二、实施步骤（按序）

### 步骤 1: 安装 TLP 并停用 PPD（冲突铁律）

```bash
sudo apt install tlp tlp-rdw
sudo systemctl stop power-profiles-daemon
sudo systemctl disable power-profiles-daemon
sudo tlp start
```

### 步骤 2: 配置 /etc/tlp.conf（离电平衡档）

```ini
# ===== CPU =====
CPU_SCALING_GOVERNOR_ON_AC=performance
CPU_SCALING_GOVERNOR_ON_BAT=powersave
CPU_ENERGY_PERF_POLICY_ON_AC=performance
CPU_ENERGY_PERF_POLICY_ON_BAT=balance_performance
CPU_BOOST_ON_AC=1
CPU_BOOST_ON_BAT=1          # 平衡档保留单核爆发（多核仍由 EPP 控制）

# ===== 平台配置（本机无 platform_profile，TLP 会自动跳过，无需配置）=====

# ===== USB / PCI / 无线 =====
USB_AUTOSUSPEND=1
RUNTIME_PM_ON_AC=on
RUNTIME_PM_ON_BAT=auto      # PCI 运行时电源管理（GPU RTD3 同层）

# ===== 磁盘 =====
DISK_APM_LEVEL_ON_AC="254 254"
DISK_APM_LEVEL_ON_BAT="128 128"   # NVMe APM（本机 APST 已 on）

# ===== WiFi =====
WIFI_PWR_ON_AC=on
WIFI_PWR_ON_BAT=on
```

> 注意：本机是 **amd-pstate-epp active 模式**，TLP 1.10 直接支持 `CPU_ENERGY_PERF_POLICY_*`。
> 不要设置 `CPU_DRIVER_OPMODE_ON_BAT=passive`（passive 不支持 EPP，会损失本机最优路径）。

### 步骤 3: 验证 EPP 切换

```bash
sudo tlp-stat -p    # 确认 governor/EPP 两套值正确
# 拔电后:
cat /sys/devices/system/cpu/cpu0/cpufreq/energy_performance_preference  # 应为 balance_performance
```

### 步骤 4: 屏幕与系统省电

```bash
# 亮度（当前 100% → 办公 40-60%）
echo 60 | sudo tee /sys/class/backlight/nvidia_0/brightness   # 或 GUI 亮度条

# Cinnamon 电源设置: 离电 5 分钟关屏、15 分钟休眠（s2idle）
# 蓝牙关闭（若不用）:
sudo systemctl disable --now bluetooth
```

### 步骤 5: GPU 功耗管理（2026-08-17 实测修正）

**实测结论**：`nvidia-smi -pl 60` **无效**（返回"成功"但墙不变——SBIOS 未开放手动写入，见 04 文档陷阱 11）。
→ 移除手动降墙方案。GPU 省电由以下自动机制负责（无需操作）：
- **RTD3 fine-grained**（实测 Enabled）：空闲时 GPU 自动进入 D3 休眠（空闲 ~2W）
- **nvidia-powerd 已启用**（2026-08-17）：空闲锁基础墙，3D 负载才动态释放

> ⚠️ 注意：nvidia-powerd 空载锁定 115W 是正常设计（Dynamic Boost 按需分配），不代表 GPU 耗电 115W——
> 实测空闲 power.draw ≈ 2-8W。

## 三、验证协议

| 指标 | 目标 | 工具 |
|------|------|------|
| 离电空闲功耗 | **≤10W**（含显示；对标 TLP 实测可低至 ~4.7-7W CPU 包） | `powerstat 60`（需拔电） |
| 离电满载频率 | ≥3.5GHz（EPP 平衡下爆发正常） | stress-ng + 采样 |
| 离电续航 | 3.5-4.5h+（PCmark 负载 ~16W 平均） | 实测放电记录 |
| 温度 | 满载 ≤85°C | sensors |
| EPP 正确 | balance_performance（拔电后） | cat sysfs |

**功耗测量（离电）**：
```bash
# 拔电后: 空闲 2 分钟读数
powerstat 5 24    # 5s 间隔 24 次, 观察 Average
# 对照: 场景 C 应更低, 场景 A 不应在此场景测
```

## 四、回滚

```bash
# 恢复 PPD + 停 TLP
sudo systemctl stop tlp && sudo systemctl enable --now power-profiles-daemon

# 恢复 EPP 默认（回 AC 场景）
sudo tlp start   # 或手动: echo performance | sudo tee /sys/devices/system/cpu/cpu*/cpufreq/energy_performance_preference

# GPU 墙回默认
sudo nvidia-smi -pl 115
```

## 五、风险清单

| 风险 | 等级 | 缓解 |
|------|------|------|
| TLP 与 PPD 残留冲突 | 中 | 严格二选一，`systemctl is-active` 双查 |
| balance_performance 下偶发卡顿（频率响应略慢） | 低 | 可升级为 `CPU_ENERGY_PERF_POLICY_ON_BAT=balance_performance` 已是最平衡点；仍卡则考虑场景 A 配置 |
| GPU RTD3 与 TLP RUNTIME_PM 冲突 | 低 | RTD3 由驱动管理，TLP 只设 PCI 层，实测无冲突（NVIDIA 官方文档支持并存） |
