# 蛟龙15K 控制中心 v2 —— 详细优化改进方案（2026-08-21）

## 一、调研总结

### 1.1 官方 ControlCenter（本地反编译，功能基准）
- RGB：28 灯效、AC/DC 分离、欢迎灯(0x767 bit7)、音乐律动(0x76F=254)、亮度5档
- 平台：5 档（Gaming/Office/Turbo/Custom/Benchmark）
- 风扇：FanBoost(0x751=0x40)、用户5档(0x81-85)、智能风扇表
- 功耗：PL1/2/4、VRM 电流
- 电池：充电阈值(0x7B9/0x7D0)、健康保护
- 硬件：触控板/摄像头/Win锁/飞行模式/麦克风/USB充电(0x767 bit4)
- 未做项：欢迎灯、音乐律动、摄像头、Fn OSD 显示、USB 充电（待测）

### 1.3 本机能力边界（已验证）
- ✅ 可用：platform_profile、kbd_backlight multicolor LED、rainbow_animation、breathing_in_suspend、fn_lock、super_key、touchpad、hwmon5(CPU/GPU温度+双风扇RPM+PWM)、充电阈值、四维联动、电量灯
- ⛔ 不可用：CPU 超频(SMU拒绝)、用户风扇5档(驱动切档覆盖)、单键背光(0x78C风险)、C6(BIOS未暴露)
- 🟡 可测：FanBoost(0x751=0x40)、欢迎灯(0x767 bit7)、音乐律动(0x76F)、USB充电(bit4)

## 三、技术设计要点

### 3.1 监控图表（A1）核心算法
```python
class RingBuffer:  # 环形缓冲，O(1)写入，固定内存
    def __init__(self, size=360): self.data=[None]*size; self.idx=0
    def push(self,v): ...
    def series(self): return 有序序列(旧→新)

# 绘制: Gtk.DrawingArea + cairo，双Y轴(左线右填充区)
# 数据源: 复用现有 get_uniwill_hwmon() + get_gpu_power()(已有5s缓存)
# 刷新: 与现有 _refresh() 共用 1s tick，零额外开销
```

### 3.2 档案系统（B1/B2）数据结构
```json
{
  "profiles": {
    "办公": {"profile":"quiet","rgb":[0,127,0],"brightness":2,
             "rainbow":false,"breathing":true,"charge_limit":80,
             "switches":{"touchpad":1,"super":1,"fnlock":0}},
    "游戏": {"profile":"performance","rgb":[255,0,0],...}
  },
  "power_binding": {"ac":"游戏","bat":"办公"},
  "active_profile": "办公"
}
```
- 应用档案 = 顺序调用现有 set_* 函数（全部已实现且免密）
- 电源绑定钩子：power-mode.sh 追加 `jcc.py --apply-binding ac|bat`（或直接读JSON由shell应用）

### 3.3 权限模型（沿用已验证方案）
- 所有写操作走 jcc-sudo-wrapper（sudoers 免密已部署）
- 新增 wrapper action：set-fanboost / set-welcome / set-music / apply-profile
- 启动时 sudo -n true 检测 + 授权按钮刷新缓存（已实现）

### 3.4 托盘（C2）
- 优先 AppIndicator（Cinnamon 原生支持）：`gi.repository.AyatanaAppIndicator3`
- 回退 Gtk.StatusIcon（X11 下仍可用）
- 图标状态着色：绿=AC平衡 / 橙=BAT省电 / 红=高温告警

## 四、实施顺序（建议 4 个工作块）
1. **工作块1**：A1 监控图表 + C1 Toast（视觉提升最明显）
2. **工作块2**：A2 FanBoost实测 + A3 风扇偏移 + C3 OSD通知
3. **工作块3**：B1 档案系统 + B2 电源绑定 + B3 颜色选择器
4. **工作块4**：C2 托盘 + B4 空闲关灯 + C4/C5 实测集成 + B5 自启

## 五、验收标准
- [ ] 图表 60s 滚动无卡顿，CPU 占用 <2%（cairo 局部重绘）
- [ ] CoolerBoost 一键生效且 10s 自动恢复
- [ ] 档案保存/应用 <1s，重启后档案完整
- [ ] 拔插电自动切换绑定档案（与四维联动共存不冲突）
- [ ] 托盘常驻，主窗关闭后后台运行，右键退出彻底退出
- [ ] 全程无密码弹窗（仅首次授权按钮）

## 六、明确不做（维持既有结论）
CPU 超频 / 用户风扇5档曲线直写(驱动覆盖) / 单键背光 / 摄像头(驱动未暴露) / OLED类(Ayuz专属) / GPU模式切换(无MUX hybrid) / AniMatrix类(无此硬件)
