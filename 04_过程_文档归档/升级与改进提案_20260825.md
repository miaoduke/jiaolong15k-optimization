### 1.3 新架构关键事实
- 前端 = CCU.WinUI.msix（64MB，572 文件）：WinUI3+.NET8 自包含，**内嵌 M2Mqtt.Net.dll（50,688B vs 5.17 的 49.5KB 几乎一致）→ MQTT 库未换，盐值大概率不变〔仍须 dump_cred 实测确认〕**

- PreinstallKit 路线（单独侧载 msix）**不采用**——避免 5.17 服务 × 5.56 前端混搭态

### 2.6 回滚预案（触发条件任一即执行）
触发 T1：V2 基线复测 FAIL≥2 项且 30 分钟内无法定位修复
触发 T2：服务无法恢复 / 13688 无法监听 / UI 无法启动三选二
触发 T3：观察期内出现温度失控、风扇持续满转不可控、电池充电行为异常

回滚步骤 R1→R7：
1. 设置→应用 卸载 机械革命控制中心(CCU.WinUI)；Remove-AppxPackage 兜底（包名从 B4 取）
2. GX 卸载器卸载服务组件（或 Inno uninstaller）
3. net stop GCUBridge 清残留进程
4. reg import oem_tree.reg（恢复 HKLM\SOFTWARE\OEM 整树；必要时 reg load hive 对照修复）
5. robocopy 还原 C:\Program Files\OEM\机械革命电竞控制台（B3 镜像 /MIR 反向）
6. 运行 D:\出厂自带\ControlCenter_5.17.49.19_Mechrevo\...exe 重装 5.17
7. 重跑 dump_cred.ps1（私有取证脚本）核对凭证 → 2.3 基线六项复测 → 通过则闭环，失败则升级为人工排查

残余风险（明示）：Inno 卸载对 UWACPIDriver.sys 共用驱动不动（无风险）；WindowsAppRuntime 1.7 残留无害；若 5.56 服务把 SMAPCTable 写出新键，reg import 前先删除 OEM 键整树再导入（步骤 4 已覆盖）。

## 五、科学纪律（继承 00_总览铁律，适用于本提案全程）
1. 单变量原则：一次实验只动一个参数
2. 写三拍：记录原值 → 写入 → 40ms 后回读，不一致立即回滚并告警
3. 温度红线：满载 >92°C 停止，>95°C 无条件冷却 120s
4. 所有实验写入留痕 %TEMP%\jcc_writelog.csv 或 mr_console 自带日志
5. 每个实验一条记录：日期/假设/操作/观测/结论/归档位置
6. BIOS/EC 固件不动；7435H 严禁刷 7735H 版本
