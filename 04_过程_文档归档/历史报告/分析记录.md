# EC 逆向分析记录 — MECHREVO 蛟龙15K (7435H+4060) / Uniwill GM5BG0E

## 背景
- 风扇根因: Linux 下 EC 温控需厂商驱动初始化; 已找到 INOU0000 设备 ECMG 操作区域 = SystemMemory @ 0xFED50000 (4096B EC 扩展 RAM MMIO)

## 已确认事实
- 温度字段: 0x43E CPTM=CPU温度、0x44F VGAT=GPU温度
- 风扇状态: 0x460 FFAN 4bit (0x02 空闲 / 0x0A 满载, 只读)
- 电源: 0x783-0x789 APL1/APL2 = 0 (AMD 平台功耗由 SMU 管理, 非 EC)
- 峰值温度记录: 0x7D8/0x7D9 = 99 (满载撞墙)
- 0x72/0x73 索引: 静态 NVRAM/CMOS 配置 (满载不变; idx 0x43=0x08 可写保持) — 排除风扇控制
- TUXEDO nb05 协议 (0x2E/0x2F 索引): 本机全 0xFF — 排除
- 0x360/0x361 EC 命令 (WrRdIO.dll 逆向, 无界14): 端口存在但无 ACK — 排除
- NBFC X6RP57TW: 0x60 PWM 写被 EC 修正 — 排除
- UWACPIDriver.sys: 方法名 ECRR/ECRW/DRCP/DWCP/DROI/DWOI/DRMM/DWMM/DR1T/DR2T/DR3T/POIR/POIW/BRMM/BWMM (ACPI 注册接口, 偏移由上层 IOCTL 传入); '0D72'/'0402' 在 overlay 证书内(误报)
- GamingCenter3_Cross.dll: 无 CLR 头 (非托管, 含加密/压缩数据, 未解包); SystrayComponent.exe 纯 UI 无 EC

## 2026-08-17 突破：风扇 PWM 寄存器确认 + EC 温控验证（满载实测）
- **PWM 寄存器**: ECMG MMIO 0xFED50000 + **0x461**(风扇1) / **0x469**(风扇2), 值域 0-255, **连续写直驱马达** (用户听声确认: 写 200 风扇转动)
- **EC 温控实测正常**: 满载 5 秒内 PWM 60→200/200 全速; 0x460 0x02→0x0A (bit3=满载); 0x464/0x46C 档位 7→18(满载)→7(空闲)
- **EC 覆写行为**: 空闲写 PWM≥200 被拉回 60 (EC 目标覆写); 满载写 255 保持; 单次写被覆写(~1.5s), 连续写(≥50ms)保持
- **满载极限**: PWM=255 全速+满载 90s → CPTM 锁 99°C → **风扇非瓶颈, 散热模组/硅脂是瓶颈** (PTM7950 方案支撑)
- 0x465/0x46D: 噪声/心跳值 (非 RPM 计数器)
- 0x463: 可写 (满载=99, 疑峰值温度/阈值); 0x462/0x467: 可写 (空闲=0, 非使能位—组合测试无效)
- 遗留: 键盘问题 (event7 零事件) 等待用户回答"内置键盘是否一直不可用"

## 2026-08-17 键盘问题完全解决 (uinput 桥)
- 根因: EC 把按键数据直接写 0x60 (不触发 IRQ1) → atkbd (中断驱动, builtin) 无法工作; atkbd 初始化失败 (Failed to enable, 启动早期 EC 未就绪)
- 证据链: 0x64 状态 INH=1 (EC 托管, 0xAE/0xFF 均无法清除); 按键 37 字节轮询可读但 IRQ1 零增长; 0xFF 复位应答 (0xAA) 触发 IRQ1 但按键数据不触发
- 键盘矩阵: 物理正常 (BIOS/Windows 均正常); 数据 = 标准 PS/2 Set 1 扫描码 (0x39=9, 0x14=T, 0xE0 5B=Win 实测确认)
- 方案: kbd_bridge.py — iopl 轮询 0x64/0x60 → 解析 Set 1 → uinput 注入 (event20), systemd 服务 kbd-bridge.service 开机自启
- 数据: 轮询 500Hz; CapsLock/A 键实测注入成功; Fn 组合键可能不走扫描码 (待验证)

## 2026-08-17 散热结论 (风扇问题关闭)
- Windows 满载 (游戏) 同样 99°C → 机器散热特性, 非 Linux 驱动问题
- 风扇物理上限 = PWM 200 (写 255 与 200 声音无差异, EC 钳制) — Windows/Linux 一致
- EC 温控正常: 满载 5 秒内 PWM→200; 空闲 60-70
- 结论: 风扇问题完全解决; 99°C = 原厂硅脂/模组极限（历史记录），后续以 ryzenadj tctl 温度墙守护管理（换脂已取消）
