## 一、降压/超频 — 硬件级锁死（结论：无可执行路径）

### 1.1 本地实测（ryzenadj v0.19.0，Rembrandt，SMU BIOS IF 18）
| 通道 | 命令 | 结果 |
|------|------|------|
| Curve Optimizer 全核 | `--set-coall=1048571`(-5) | **`set_coall is rejected by SMU`** |
| 强制 OC 使能 | `--enable-oc` | **`set_enable_oc is rejected by SMU`** |
| 强制频率 | `--oc-clk=4200` | "Successfully set"（但 enable-oc 被拒 → 无效） |
| 强制 VID | `--oc-volt=48` | **`set_oc_volt is not supported on this family`** |

### 1.2 网络佐证（为何锁）
- AMD 官方仅对部分芯片开放 CO（7940HS 有、7840U 无；Zen3+ 移动端基本全锁）——安全策略 + 平台授权
- Framework 论坛实测：Zen2/Zen3 上"offset undervolt"会被 boost 算法反补偿（电压追平/时钟拉伸）——只有 CO 才真正生效——而 CO 被锁
- Rembrandt 系 CO 支持状态：ryzenadj 的 CO 代码为 Phoenix/Hawk Point 新增，Rembrandt SMU 无此命令 → 拒绝
- GPD 6800U 案例：Rembrandt 上 TDP 调整（-a/-b/-c）部分机型无效，仅 tctl-temp 可靠——**本机实测 TDP 墙有效**（80/100/80W 双烤稳定，优于 GPD）

### 1.3 唯一理论路径（不推荐）
- **Smokeless_UMAF**：运行时解锁 BIOS 隐藏菜单（AMD CBS → Curve Optimizer）——ROG Ally 等 Phoenix 成功案例——但：BIOS 版本兼容未知 + 改隐藏设置有变砖风险 + 7435H 无成功先例 → **记录在案，不执行**

### 1.4 本机 PM Table 可读（v450005，offset 数据）
STAPM 80W/PPT FAST 100/SLOW 80/TDC 70/EDC 140/APU 20/Tctl 92（我们的设置写入后 PM 表可见）/频率电压实时值（3074MHz/1.41V 满载级）——监控数据源可用

### 10.1 🚨 EC 真实内存基址 = 0xFED50000（DSDT ECMG 操作区）——假象根因
- DSDT 反编译(386 方法)泄露: `OperationRegion (ECMG, SystemMemory, 0xFED50000, 0x1000)`
- **/dev/mem 直读 FED50000 完全正常**: FED50769=0x32(当前红)/FED5078C=0x88/0x43E=0x3C(60°C)
- **"0x78C 恒 0xFF" + "通道不可靠" = 基址错误(FEDC0000 未映射→全 FF)假象——已根治**
- ec_tool.py: EC_BASE=FED50000 + 主路径 read_mem(WKBC/RKBC 备用)——读写全验证
- 推论: 之前用 RKBC 读的所有数据仍正确(地址对的), 只是绕路; 现在直读更快

### 15.1 EC 4K 地址空间穷尽结论
| 区域 | 内容 | 可操作性 |
|------|------|---------|
| 0x000-0x3FF | 固件校准/镜像区（0x300/0x320 风扇校准 3800 双镜像；0x240=0xD40 同数据；0x2E0/0xDE0 A5 双现；0x380-0x3A0 16 位系数表） | 低（数据区） |
| 0x400-0x6FF | 传感器/校准（SystemID 0x456、风扇 RPM 0x46C、电池循环 0x4A6、充电阈值 0x4C0 系、3800 校准 0x53A） | 低 |
| 0x700-0x7FF | **功能寄存器区**（RGB 0x769-76B/触发 0x767/亮度模式 0x78C/风扇 0x751/充电 0x7B9/支持位 0x765-766/Fn 锁 0x74E） | 高 |
| 0x800-0xFFF | 0xD40/0xDE0 镜像 + **风扇表 0xF00-0xF5F**；其余空白 | 高（风扇表） |

### 15.2 风扇表结构解密（最终版）
- **CPU 表1**：0xF00（8 端点+2 起点）+ 0xF10（11 速度：00+10 项）
- **CPU 表2**：0xF20（00+10 项——模式切换只改这里：balanced 96×9=150 vs quiet 6E×9=110）
- **GPU 表1**：0xF30 + 0xF40；**GPU 表2**：0xF50（balanced 87=135 vs quiet 5A=90）
- quiet 表 0xF5D=FD（FAN_TABLE_MAGIC 呼应）；速度单位≈PWM%（3800RPM=100% 校准：48%×3800=1824≈实测 1764✓）
- **生态项确认**：改 0xF20/0xF50 即自定义风扇曲线（GPU 表2 是驱动未覆盖的扩展点）
