# SMU可写性实测报告 (2026-08-28)

## 测试环境
- CPU: AMD Ryzen 7 7435H (Zen 3+ / Rembrandt-H Refresh)
- SMU BIOS Interface Version: 18
- PM Table Version: 450005
- ryzenadj: v0.19.0
- 方法: Start-Process -Verb RunAs (管理员权限)

## SMU参数可写性测试结果

| 参数 | 命令 | 结果 | 说明 |
|------|------|------|------|
| STAPM LIMIT | --stapm-limit=75000 | ✅ 成功 | 持续功耗墙可调 |
| PPT FAST | --fast-limit=90000 | ✅ 成功 | 瞬时功耗墙可调 |
| PPT SLOW | --slow-limit=70000 | ✅ 成功 | 平均功耗墙可调 |
| Tctl | --tctl-temp=95 | ✅ 成功 | 温度墙可调 |
| Curve Optimizer | --set-coall=4294967291 | ❌ 被拒绝 | SMU锁定 |
| OC Enable | --enable-oc | ❌ 被拒绝 | SMU锁定 |
| Voltage Override | --oc-volt=40 | ❌ 不支持 | 此CPU系列不支持 |

## 当前SMU默认值

| 参数 | 值 | 说明 |
|------|-----|------|
| STAPM LIMIT | 80W | 持续功耗墙 |
| PPT FAST | 100W | 瞬时功耗墙 |
| PPT SLOW | 80W | 平均功耗墙 |
| PPT APU | 80W | APU功耗墙 |
| TDC VDD | 70A | VRM电流限制 |
| EDC VDD | 140A | 最大电流限制 |
| Tctl | 99°C | 温度墙 |

## 结论

1. **功耗墙完全可调**: STAPM/PPT FAST/PPT SLOW/Tctl均可通过ryzenadj调整
2. **电压控制被锁定**: Curve Optimizer、OC Enable、Voltage Override均被SMU拒绝
3. **这是BIOS层面的锁定**: Uniwill BIOS禁用了SMU电压控制功能
4. **唯一的省电路径**: 降低功耗墙（STAPM/PPT）来限制CPU最大功耗

## readjustService.ps1 默认值问题

脚本默认值(AC模式):
- fast_limit: 46000 mW = 46W
- slow_limit: 25000 mW = 25W

这些值**远低于**当前SMU默认值(80W/100W)。如果启用此服务，必须先修改脚本中的值。

建议值(匹配smu_profile.json office模式):
- stapm_limit: 35000 (35W)
- fast_limit: 65000 (65W)
- slow_limit: 65000 (65W)
- tctl_temp: 85
