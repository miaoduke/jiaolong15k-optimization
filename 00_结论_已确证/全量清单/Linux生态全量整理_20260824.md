## Linux vs Windows 生态对比

| 维度 | Linux | Windows |
|------|-------|---------|
| EC访问方式 | /dev/mem 直写 + ACPI RKBC/WKBC | WMI AcpiTest_MULong + MQTT |
| EC读写范围 | 全地址(0x000-0xFFF) | 全地址(WMI) + MQTT受限 |
| 管理员需求 | root | 部分需要 |
| RGB键盘 | ✅ 直写+LED class | ✅ MQTT function协议 |
| 风扇PWM直驱 | ✅ 0x461/0x469 | ❌ WMI路径不支持 |
| 温度读取 | ✅ /dev/mem 0x43E | ✅ WMI 0x43E |
| 充电阈值 | ✅ 0x7B9 | ✅ WMI 0x7B9 |
| CPU调优 | ⛔ SMU锁死 | ⛔ SMU锁死 |
| GPU调优 | nvidia-smi/NVAPI | nvidia-smi/NVAPI/Afterburner |
| 风扇曲线 | ✅ uniwill驱动管理 | ✅ MQTT SET_CURVE |
| 性能模式 | ✅ platform_profile | ✅ MQTT OPERATING_* |
| 温度墙 | ✅ ryzenadj(SMU) | ✅ MQTT CpuTccOffset |
| 优势 | 精细控制/无限制/内核驱动 | GUI友好/MQTT协议/官方兼容 |
