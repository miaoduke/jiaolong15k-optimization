# 蛟龙15K 极限续航优化方案 v1.0
> 基于网络调研 + 实测数据，科学延长电池续航

## 电池基本信息
- 设计容量：62,320 mWh
- 当前健康度：100%（新机）
- CPU：AMD Ryzen 7 7435H (45W TDP, 无iGPU)
- GPU：NVIDIA RTX 4060 Laptop
- 系统：Windows 11 Pro Build 26200

## 优化分层（按收益排序）

### 第一层：关键优化（预计+1-2小时）

#### 1. 关闭后台应用权限
```powershell
# 设置非必要应用禁止后台运行
# 设置 > 应用 > 已安装的应用 > 点击应用 > 高级选项 > 后台应用权限 > 从不
```
**实测案例**：DigitBin测试发现，关闭后台应用+Energy Saver可延长约90分钟续航。

#### 2. 禁用不必要的Windows服务
```powershell
# 高收益服务禁用清单
services = @(
    "DiagTrack",                    # 遥测
    "SysMain",                      # Superfetch
    "WSearch",                      # Windows搜索索引
    "wercplsupport",                # 错误报告
    "PcaSvc",                       # 程序兼容性
    "WerSvc",                       # Windows错误报告
    "RetailDemo",                   # 零售演示
    "MapsBroker",                   # 离线地图
    "lfsvc",                        # 地理位置
    "SharedAccess",                 # Internet连接共享
    "RemoteRegistry"                # 远程注册表
)

foreach ($svc in $services) {
    Stop-Service $svc -Force -ErrorAction SilentlyContinue
    Set-Service $svc -StartupType Disabled -ErrorAction SilentlyContinue
    Write-Host "已禁用: $svc"
}
```

#### 3. 电源计划深度调优
```powershell
# 创建极限省电计划
powercfg /duplicatescheme 381b4222-f694-41f0-9685-ff5bb260df2e
# 重命名
powercfg /changename {GUID} "MR-极限续航"

# CPU功耗墙
powercfg /setacvalueindex {GUID} SUB_PROCESSOR PROCTHROTTLEMAX 50  # 最大50%
powercfg /setacvalueindex {GUID} SUB_PROCESSOR PROCTHROTTLEMIN 5   # 最小5%

# 禁用Turbo Boost（关键！）
powercfg /setacvalueindex {GUID} SUB_PROCESSOR PERFBOOSTMODE 0

# 关闭PCIe链路状态电源管理
powercfg /setacvalueindex {GUID} SUB_PCIEXPRESS ASPM 2

# 关闭USB选择性挂起
powercfg /setacvalueindex {GUID} 2a737441-1930-4402-8d77-b2bebba308a3 48 0

# 关闭硬盘AAM/APM（SSD不需要）
powercfg /setacvalueindex {GUID} DISK IDLEAC 0
```

## 注意事项

1. **禁用服务前**：创建系统还原点
2. **Turbo Boost关闭**：会影响CPU性能
3. **刷新率降低**：会影响显示流畅度
4. **部分设置需重启**才能生效
