## 三、Topic 与命令全集（抓包实证）

### 请求/响应模式
```json
→ 发布 {"Action":"GETSTATUS"} 到 Xxx/Control
← 收到 {"...完整状态JSON"} 于 Xxx/Status
```

### Topic 清单
| Topic 方向 | 功能 |
|-----------|------|
| Fan/Control ↔ Fan/Status | 性能模式/PL/TGP/OC/风扇全量状态 |
| Setting/Control ↔ Setting/Status | Win键锁/灯条/USB充电/独显直连/OSD/显示模式/小键盘/Fn键/触控板/AC恢复 |
| LCHWOC/Control ↔ LCHWOC/Status | 液冷超频 |
| BatteryProtection/Control | 电池保护（Action: HEALTHYMODE 等） |
| System/BatteryProtection | 电池状态上报 |
| Customize/* | OEM 定制信息 |
| System/Control (GetGraphicInfo, System_OFF) | 系统/GPU 信息、关机 |
| Keyboard/Ctrl | 键盘灯 |
| MyRgbLightbar/*, HidLightbar_*/Ctrl | RGB 灯效 |
| Languages/Control (SET/GET/EnableTray) | 语言 |
| OSDTpDectect/Language | OSD 文案 |
| TouchPadWorkArea/Control | 触控板工作区 |
| WhisperMode/Status, GPUDevice/Status, EC/Control, Display/* | 其他 |

### Fan/Control 可用 Action（部分实证）
`GETSTATUS`、`GET_FAN_SPEED_CURVE_SETTING`；Setting: `HEALTHYMODE`；System: `System_OFF`、`GetGraphicInfo`
（写指令如 SET_PL/SET_MODE 等按同格式推断，字段名见下方 Status 全字段）

## 五、自制控制台最小示例（PowerShell）

见同目录 `mqtt_listen.ps1`（监听）/ `mqtt_publish_test.ps1`（发布）。
组包要点：MQTT 3.1.1 CONNECT 带 username/password 字段（flags 0xC2），或直接用任意 MQTT 库（paho-mqtt 等）：

```python
import paho.mqtt.client as mqtt, json
c = mqtt.Client(client_id="PluginClient_5")
c.username_pw_set("PluginClient_User_5", "PluginClient_Pwd<REDACTED>[REDACTED]_5")
c.connect("127.0.0.1", 13688)
c.subscribe("#")
c.publish("Fan/Control", json.dumps({"Action":"GETSTATUS"}))
```

## 六、风险提示
- 不要使用官方正在占用的 ClientId 槽位（会顶掉官方客户端）
- 写操作建议只在本机硬件边界内（服务端有 Min/Max 钳制保护，越界值会被忽略）
- GCUBridge 更新版本可能更换密码盐值（Pwd[REDACTED]），届时用同目录 dump_cred.ps1 重新提取
