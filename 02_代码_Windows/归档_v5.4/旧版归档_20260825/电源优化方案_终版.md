## 一、性能模式切换的具体参数改变（实测diff）

| 参数 | 办公(Mode2) | 均衡(Mode1) | 狂暴(Mode3) |
|------|-----------|-----------|-----------|
| CPU PL1/PL2 | 35W | 65W | 80W |
| CPU PL4 | 100W | 100W | 100W |
| AMD SPL/SPPT | 35W | 65W | 80W |
| AMD FPPT | 100W | 100W | 100W |
| CPU温度墙 | 99°C | 99°C | 99°C |
| 风扇曲线 | M2T1 | M1T1 | M3T1 |
| GPU核心偏移 | 0 | 0 | +100MHz |
| GPU显存偏移 | 0 | 0 | +500MHz |
| GPU TGP | 关/115W | 开/115W | 开/115W |
| cTGP-GN21 | 关 | 关 | 开/175W |
| OC开关 | - | - | 开 |

切档 = GCUService一次性向EC写入整套预设(约17个寄存器同时变更)。

## 三、电源场景方案

### 四场景(已在v5.2实现基础版)
游戏=高性能+狂暴+游戏显示+强冷+100%
办公=平衡+办公+护眼+60%
影音=平衡+均衡+视频+80%
移动=平衡+办公+强冷关+40%

### Windows层优化(需管理员一次性设置)
- Boost模式: AC=2(Aggressive) DC=0(Disabled)
- EPP: AC=0(最大性能) DC=80(最大效率)
- PROCTHROTTLEMAX: DC=80%
- HAGS: HwSchMode=2
- 创建节电计划: powercfg -duplicatescheme a1841308

### 后续可加
- 智能切换(前台全屏检测→游戏场景)
- 拔电自动切换(电池状态监听)
- 场景自定义保存
- EPP滑条
- 刷新率切换API

## 四、穷尽调研 — 还有什么可以实现

### 已确认可新增
1. GPU TGP 140W(nvidia-smi -pl, 需管理员)
2. 刷新率切换(EnumDisplaySettings+ChangeDisplaySettings)
3. 屏幕亮度(WmiSetBrightness, 已在场景中)
4. EPP能效偏好(powercfg, 需管理员)
5. Windows游戏模式开关(注册表)
6. HAGS开关(注册表)

### 已确认不可实现
- CPU降压(SMU锁死)
- 内存OC(EC不支持)
- 独显直连(无MUX)
- 液冷(无硬件)
- 灯条(无硬件)
- 充电阈值EC直写(已通但本机寄存器=0, 可能需BIOS更新)

### 需不同路径
- GPU VF曲线降压(Afterburner)
- AMD PBO/CO(SMU拒绝, 除非BIOS解锁)
