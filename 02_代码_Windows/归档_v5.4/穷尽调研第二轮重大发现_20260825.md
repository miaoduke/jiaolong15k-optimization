## 一、王炸发现: roj234/mechrevo_ec_api (同通道先行者)

第三方逆向机械革命控制 API, **与我们同走 \\\\.\ACPIDriver 通道**, 功能覆盖:
16点风扇曲线读写 · PL1/PL2/PL4功耗墙 · TCC偏移 · GPU超频/TGP/DynamicBoost · NVRAM · 键盘灯/RGB灯条 · AC恢复 · 关机USB充电 · Profile JSON

### 其寄存器表 × 本机(GM5BG0E/AMD) 只读交叉验证结果
| 地址(十六进制换算后) | roj234 标注 | 本机读数 | 判定 |
|---------------------|------------|---------|------|
| **0x75B / 0x75C** | FAN1/FAN2 PWM | 60/60 | ✅ **与0x461镜像**(同值60) |
| **0x783/0x784/0x785** | PL1/PL2/PL4 (W) | **65/65/100** | ✅ 活! 与当前办公档(EPP60)吻合 |
| 0x7C5 bit7 | 硬件曲线开关 | 0x08(bit7=0)=关 | ✅ 自洽 |
| **0x7B9** | 充电上限% | 80 | ✅ 即我方"起始阈值80"同源 |
| 0x49F | 适配器功率(编码) | 10 | ✅ 活(编码待解) |
| 0x726 bit3 | AC恢复 | 8(bit3=1) | ✅ |
| 0x743 | TGP/DynamicBoost ctrl | 5 | ✅ 活 |
| 0x7A6 | 触摸板 | 40 | ✅ 活 |
| 0x78C | 键盘背光 | 8 | ✅ 活 |
| 0xF00..0xF50 区 | 16点曲线表×6 | 全None | ❌ 本模具无此区(或异址) |

### 协议级收获(源码实证)
1. **Duty 编码 = raw ÷ 2** → 0x461=60 即 **30%**
   - RPM 自洽验证: 0x464:0x465 = 6:224 → **1760 RPM** @ 30% duty ✓ 合理
   - 🔴 **我方 get_fan_duty/get_gpu_duty 显示虚高一倍**(bug级, 待NO-OP终验后修)
2. **硬件曲线协议**(roj234 机型): 写0xF00区16点表 → 0x7C5 bit7 使能 —— 但**本模具无此表区**, C1仲裁问题仍存, 软件曲线仍为主路线
3. 写入无解锁序列, 直写即可(降低实施难度)
