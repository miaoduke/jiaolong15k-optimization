## 一、今日突破（M0+M2 提前完成）

### 1.1 厂商 DLL 导出函数穷尽枚举（PE 解析，19 个）
```
ReadCMOS ReadEC ReadIO ReadIndexIO ReadMEMB ReadPCI SMAPCTable
TempRead1-3 TempWrite1-3 WriteCMOS WriteEC WriteIO WriteIndexIO WriteMEMB WritePCI
```

### 1.2 关键签名运行时破解（只读实验法）
| 函数 | 签名 | 验证证据 |
|------|------|---------|
| **ReadEC** | `int ReadEC(int addr)` 返回即数据 | 0x44F=42°C 与 nvidia-smi 45°C 吻合；0x740=16 (ProjectID) |
| **WriteEC** | `int WriteEC(int addr, int val)` | 回写原值到 0x769 → 回读一致、零副作用 |
| ReadMEMB | `int ReadMEMB(int physAddr)` | ReadMEMB(0xFED50740)=16 == ProjectID ✓ (MMIO 直读通道可用) |
| TempRead1 | 非 void/int 单参 | 返回回显参数，需 IDA 进一步确认（非必需，ReadEC 已覆盖） |

## 七、白色背光诊断 → 值域重大发现（2026-08-23，diag_white_20260823.ps1）

### 7.1 用户报告"白色无效"→ 寄存器级诊断
| 实验 | 结果 |
|------|------|
| 红通道量程探测 | 60/80/100/**200/255 全部原样接受**；唯独 128 回读=0 |
| 白色候选写入 | (255,255,255)/(50,50,50)/(49,49,49)/(35,35,35) 寄存器级全部接受 |
| 黄色双通道满载对照 | (255,255,0) 接受 |
| commit(0x767 bit5) 整窗 diff | 仅 0x769/76A/76B 自身变化，无隐藏副作用寄存器 |

### 7.2 结论：EC 键盘灯色值为 **0-255 全量程**，不是 0-50！
- 出厂默认 (1,50,50) 青其实是 **~20% 暗青**；此前所有颜色按钮都只跑 20% 亮度
- "白色无效"根因: (50,50,50)=三通道同时 20% 混光，视觉上暗淡近无变化；真白 = (255,255,255)
- ⚠️ **硬件坑位: 色值字节写 128 (0x80) 会钳位为 0** —— 橙色用 (255,120,0) 而非 (255,128,0)
- 诊断脚本: `diag_white_20260823.ps1`（自动恢复原色）；结果存档 `diag_white_result_20260823.txt`
