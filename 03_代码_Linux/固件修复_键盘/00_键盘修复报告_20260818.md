# 蛟龙15K (GM5BG0E) 键盘修复报告

- **机器**: MECHREVO Jiaolong15K Series GM5BG0E (蛟龙15K)
- **CPU**: AMD Ryzen 7 7435H (警告: 禁止刷 7735H 通刷 BIOS, 会变砖)
- **BIOS**: N.1.23MRO20 (2024-02-06)
- **系统**: Linux Mint 22.3, 内核 7.0.0-29-generic, Cinnamon X11
- **修复日期**: 2026-08-18
- **状态**: 全部完成并验证

---

## 一、问题现象

内置 PS/2 键盘 (AT Translated Set 2) 部分键位失效:

- 字母行、数字行、F 功能键区、右侧标点、方向键 — 稳定失效
- Fn+F4 (WiFi 开关) / Fn+F5 (触控板开关) 无反应
- 外接 USB 键盘正常 (AONE Varmilo), 触摸板正常

## 二、诊断过程

### 2.1 排除驱动缺失

检查 Windows 驱动备份 (出厂自带/驱动备份):
- 无任何专用键盘驱动, 仅有标准 i8042prt / kbdclass / kbdhid
- 结论: 问题不在驱动, 而在固件/ACPI 层面

### 2.2 定位根因 (键盘主键区)

系统日志出现:
```
atkbd serio0: Failed to deactivate keyboard on isa0060/serio0
atkbd serio0: Failed to enable keyboard on isa0060/serio0
```

根因: BIOS DSDT 中 PS2K 键盘中断极性声明错误

- DSDT 声明: IRQ (Edge, ActiveLow, Shared) {1}
- 硬件实际: ActiveHigh
- Linux 6.0+ 内核不再自动修正极性错误
- 主板 GM5BG0E 不在内核 irq1_edge_low_force_override[] 兼容表中
- 结果: IRQ1 中断无法触发 → atkbd 初始化失败 → 键位失效

### 2.3 定位 Fn 键问题

使用 acpi_listen 捕获 Fn 键事件:

| 按键   | 事件                         | 通道     |
|--------|------------------------------|----------|
| Fn+F4  | wmi PNP0C14:00 000000d2      | WMI 事件 |
| Fn+F5  | button/f24 F24 ... K         | F24 按键 |

系统无任何程序处理这两个事件 → Fn 键"看起来"没反应。

## 三、修复方案

### 3.1 主键盘: DSDT Override

1. 提取 DSDT: cat /sys/firmware/acpi/tables/DSDT > dsdt.dat
2. 反编译: iasl -d dsdt.dat
3. 修改键盘 IRQ 极性: ActiveLow → ActiveHigh
4. 提升 DSDT 版本号: 0x1072009 → 0x107200A (确保 override 生效)
5. 重新编译: iasl -tc dsdt.dsl
6. 部署:
   - 打包 initrd 固件: /boot/acpi_override (内含 kernel/firmware/acpi/dsdt.aml)
   - GRUB 配置: /etc/default/grub 添加 GRUB_EARLY_INITRD_LINUX_CUSTOM="acpi_override"
   - sudo update-grub

验证 (重启后):
```
dmesg: ACPI: DSDT ACPI table found in initrd [kernel/firmware/acpi/dsdt.aml]
dmesg: Table Upgrade: override [DSDT-...-0107200A]
atkbd Failed 错误消失, IRQ1 计数 3 → 141
```

### 3.2 Fn 功能键: acpid 事件处理

安装 acpid, 创建事件规则:

| 组件 | 路径 | 作用 |
|------|------|------|
| 脚本 | /usr/local/bin/fn-f4-wifi.sh      | Fn+F4: 切换 WiFi   |
| 脚本 | /usr/local/bin/fn-f5-touchpad.sh  | Fn+F5: 切换触控板 |
| 规则 | /etc/acpi/events/fn-f4-wifi       | event=wmi PNP0C14:00 000000d2 |
| 规则 | /etc/acpi/events/fn-f5-touchpad   | event=button/f24 |

关键坑: NetworkManager 1.46 不支持 nmcli radio wifi toggle 参数!
必须改为先查状态再反向设置:

```bash
STATE=$(nmcli -t -f WIFI radio | cut -d: -f2)
if [ "$STATE" = "enabled" ]; then nmcli radio wifi off; else nmcli radio wifi on; fi
```

触控板切换 (需 X11 环境变量):
```bash
DISPLAY=:0 XAUTHORITY=/home/<USER>/.Xauthority \
  xinput set-prop "UNIW0001:00 093A:0255 Touchpad" "Device Enabled" 0/1
```

验证: journalctl -t fn-f4 -t fn-f5 出现
WiFi toggled: disabled/enabled 与 Touchpad disabled/enabled, 实际按键往返切换成功。

## 四、最终结果

| 问题 | 根因 | 修复 | 状态 |
|------|------|------|------|
| 主键盘多区失效 | DSDT IRQ 极性错误 (ActiveLow→ActiveHigh) | DSDT override | 完成 |
| Fn+F5 触控板开关 | EC 上报 F24 无处理 | acpid + xinput | 完成 |
| Fn+F4 WiFi 开关 | EC 上报 WMI 无处理 + NM 1.46 无 toggle 参数 | acpid + nmcli on/off | 完成 |

所有修复持久生效 (GRUB 加载 DSDT / acpid 服务自启), 重启不丢失。

## 五、回滚方法

### DSDT Override 回滚
```bash
sudo rm /boot/acpi_override
# 编辑 /etc/default/grub, 删除 GRUB_EARLY_INITRD_LINUX_CUSTOM="acpi_override" 行
sudo update-grub
```

### Fn 键修复回滚
```bash
sudo rm /etc/acpi/events/fn-f4-wifi /etc/acpi/events/fn-f5-touchpad \
        /usr/local/bin/fn-f4-wifi.sh /usr/local/bin/fn-f5-touchpad.sh
sudo systemctl restart acpid
```

## 六、长期注意事项

1. BIOS 升级: 只刷机械革命官方针对 7435H 的版本; 刷 BIOS 后 DSDT override 会失效,
   需重新提取修改 (参考 fix-keyboard.sh, 本目录 DSDT文件/ 有修改版可对比)。
2. 内核升级: 不影响, DSDT override 由 GRUB 加载。
3. 若重装系统: 需重新执行 fix-keyboard.sh 与 install-fn-fix.sh (脚本在本目录 脚本/ 下)。
4. 回滚后如需恢复, 重新执行上述脚本即可。
